# Exercise: no.5
## Chase branch that escaped 

## What this exercise taught me
This exercise taught me how to change the *hash* of a branch and point it to another hash.  
In this case, I changed the hash of the `chase` branch to the hash of the Escaped.  
Moving forward, I changed my head back to the `chase` branch, finally verifying it.

The following command is used:
```sh
git branch -f <branch-name> <hash>
```
