## Resolve a merge conflict 

## What this exercise taught me
This exercise taught me how to manually merge two branches. The issue I faced was caused by my changing the `equations.txt` file in both the branches.
Consequently, I couldn't pass the git verify command because I was using more commits than required. 

To solve it, I tried to merge it first and then Git will show which file is having the merge error.  
From there I will edit the final `equations.txt` file, and then I stage it and commit it; as a result, I won't need more number of commits.
