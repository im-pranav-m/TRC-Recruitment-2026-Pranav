For this excercise, we perform the following steps:

1. Connect the LDR, Ultrasonic, and Leds to the ESP32. 
2. Use a basic distance calculation maths to calculate the distance.
3. Analog read the LDR luminosity and write it to the LED brightness value. 

In the end we used IF-ELSE to blink the LED.
